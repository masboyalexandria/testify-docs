# Go API

- [github.com/stretchr/testify](https://testify-docs.readthedocs.io/en/latest/go-api/package-root.md): Module testify is a set of packages that provide many tools for testifying that your code will behave as you intend.
- [github.com/stretchr/testify/assert](https://testify-docs.readthedocs.io/en/latest/go-api/pkg-assert.md): Package assert provides a set of comprehensive testing tools for use with the normal Go testing system.
- [github.com/stretchr/testify/assert/internal/unsafetests](https://testify-docs.readthedocs.io/en/latest/go-api/pkg-assert-internal-unsafetests.md): This package exists just to isolate tests that reference the unsafe package.
- [github.com/stretchr/testify/assert/yaml](https://testify-docs.readthedocs.io/en/latest/go-api/pkg-assert-yaml.md): Package yaml is just an indirection to handle YAML deserialization.
- [github.com/stretchr/testify/http](https://testify-docs.readthedocs.io/en/latest/go-api/pkg-http.md): Deprecated: Use net/http/httptest instead.
- [github.com/stretchr/testify/internal/difflib](https://testify-docs.readthedocs.io/en/latest/go-api/pkg-internal-difflib.md): Package difflib is a partial port of Python difflib module.
- [github.com/stretchr/testify/internal/spew](https://testify-docs.readthedocs.io/en/latest/go-api/pkg-internal-spew.md): Package spew implements a deep pretty printer for Go data structures to aid in debugging.
- [github.com/stretchr/testify/mock](https://testify-docs.readthedocs.io/en/latest/go-api/pkg-mock.md): Package mock provides a system by which it is possible to mock your objects and verify calls are happening as expected.
- [github.com/stretchr/testify/require](https://testify-docs.readthedocs.io/en/latest/go-api/pkg-require.md): Package require implements the same assertions as the assert package but stops test execution when a test fails.
- [github.com/stretchr/testify/suite](https://testify-docs.readthedocs.io/en/latest/go-api/pkg-suite.md): Package suite contains logic for creating testing suite structs and running the methods on those structs as tests.
